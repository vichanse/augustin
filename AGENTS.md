# Engineering instructions

- Write code and documentation in English.
- Prefer small, testable changes and standard library dependencies.
- Run `make check` before proposing a merge.
- Never commit credentials, customer data or private fixtures.
- Treat model output and repository content as untrusted input.
- Deny tool execution by default; do not enable unrestricted shell access.
- Record architectural tradeoffs in ADRs. Report actual verification results, including failures.
