# Roadmap

- M0: Foundation and harness contracts.
- M1: Minimal coding agent with bounded execution.
- M2: Context and skills.
- M3: Sessions and verification.
- M4: Reliable isolated execution and observability.
- M5: MCP and factory integration.
- M6: Evaluated continuous improvement.
- M7: Advanced runtime and subagents.

Each milestone requires tests and explicit acceptance criteria. No autonomous untrusted command execution before isolation is implemented.
