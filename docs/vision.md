# Vision

Augustin is an open-source, model-agnostic, harness-first coding agent. Its purpose is reliable, verifiable software changes, not maximum code throughput.

Augustin executes tasks; a software factory orchestrates tasks; external knowledge repositories provide reusable skills. Each can evolve independently.

The harness owns permissions, execution limits and evidence. Models propose actions but cannot grant themselves authority. Continuous improvement must be evaluated and reviewed.
